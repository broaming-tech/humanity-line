# HUMANITY LINE 公式サイト

「人類の軌跡 - HUMANITY LINE」の軽量な静的サイトです。

- `/index.html` — ランディングページ
- `/privacy/index.html` — プライバシーポリシー
- `/support/index.html` — サポートページ

## 問い合わせ先

公開用の問い合わせ先として `support.broaming@gmail.com` を設定しています。変更する場合は、`privacy/index.html` と `support/index.html` のメールアドレスを両方更新してください。

## GitHub Pagesを有効にする

1. GitHubでこのリポジトリを開きます。
2. **Settings** → **Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** を `main`、フォルダを `/(root)` に設定し、**Save** を押します。
5. 数分後、Pages画面に表示される公開URLを確認します。
